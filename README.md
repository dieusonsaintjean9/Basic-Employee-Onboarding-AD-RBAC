# Basic-Employee-Onboarding-AD-RBAC

## Problem Statement 
Northstar Medical Group’s Active Directory Domain was previously operated by a Third-Party MSP. There were no procedures in place, as well as no documentation, regarding how to perform User Account Management. Departmental Organization was poorly organized and therefore did not exist. This has created several security-related issues that have prevented Northstar Medical Group from properly managing users and have created obstacles to identity management processes. Northstar Medical Group is a Health Care organization. Due to this, it is even more imperative that Northstar Medical Group maintains a Secure Identity Infrastructure. A Secure Identity Infrastructure is essential to protect sensitive information about its patients as well as support its Compliance Requirements.


## Solution Overview
The Solution was to create a New Active Directory Domain named “NMG.com”. Structured Domains give the ability to Organize Users, Computers, Groups, Access Permissions, etc. across the entire organization. The new Domain will enable Northstar to implement a Consistent Identity Management Process. In addition, the new Domain will provide Northstar with the opportunity to implement Organizational Units (OU’s), Security Groups, Access Controls, and Account Management Procedures in subsequent phases of the Project. Northstar addressed many existing issues by replacing its current Unstructured Environment with a Standardized Active Directory Domain. Additionally, the creation of a new domain has provided Northstar with a Foundation upon which they can improve their Security, Simplify Administration, and prepare themselves for Hybrid Integration with Microsoft Azure in Future Phases of their Project.
